# Категории и дежурства (плагин herdr `anton.sidebar`)

Свои категории в левой панели herdr, вынос копии проекта (worktree) из группы, пометка дежурных агентов,
горячие клавиши для прыжка к проекту и звёздочки на важных проектах.
Описание: `docs/superpowers/specs/2026-10-01-sidebar-categories-design.md`.

## Установка

    herdr plugin link C:\Users\me\projects\herdr-sidebar
    node C:\Users\me\projects\herdr-sidebar\src\cli.js install

Окно: `prefix+shift+s` или правой кнопкой на рабочем месте → «Категории и дежурства».

## Горячие клавиши

В окне плагина встаньте на проект и нажмите `k` (или Enter → «Горячая клавиша…»), выберите клавишу:
Alt+5…Alt+0 или F1…F12 (Alt+1…4 заняты звёздочками, F11 оставлена терминалу), либо своё сочетание. У проекта с несколькими вкладками
можно выбрать, на какую вкладку прыгать. Клавиша видна в боковой панели рядом с названием.

Как устроено: плагин пишет в config.toml (между метками `anton.sidebar keys`) привязку клавиши к действию
`anton.sidebar.jump-N`, а действие находит проект по имени (и папке, если имён два) — так клавиша
переживает переименование и перезапуск herdr. Занятые herdr или другими плагинами клавиши не предлагаются;
если herdr не примет новую привязку, файл возвращается как был.

## Звёздочки

Четыре вида звёздочек, у каждого свой цвет и своя клавиша:

| Вид | Клавиша | Цвет |
|---|---|---|
| ★1 Мой проект | Alt+1 | жёлтый |
| ★2 Первая работа | Alt+2 | бирюзовый |
| ★3 Вторая работа | Alt+3 | розовый |
| ★4 Третья работа | Alt+4 | оранжевый |

Поставить: в окне плагина встаньте на проект (или на копию — раскрыть копии стрелкой →), нажмите `s`, потом
цифру вида. Там же «Снять звёздочку». В боковой панели перед названием появляется цветная ★ с номером.

`Alt+N` при закрытом окне: если вы уже в проекте вида N — к следующему такому ниже по панели (с последнего
снова на первый); если в другом — к проекту вида N, куда эта клавиша водила в прошлый раз. Привязки лежат
в блоке `anton.sidebar keys` и ведут к действиям `anton.sidebar.star-1…4`; звёздочка, как и горячая клавиша,
переживает переименование и перезапуск herdr. Звёздочки, поставленные до появления видов, считаются «Мой проект».

    herdr-duty stop
